Clustering and Association Rule Mining

## Project Overview

In this module I learned about Clustering and Association Rule Mining using Machine Learning algorithms.

I used two datasets for this practical.

## Datasets Used

1. Mall Customer Segmentation Dataset
2. Groceries Dataset

## Algorithms Used

### Clustering
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN Clustering
- Elbow Method

### Association Rule Mining
- Apriori Algorithm
- FP-Growth Algorithm

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Mlxtend

## Work Done

- Loaded and explored the datasets.
- Performed data preprocessing.
- Applied clustering algorithms.
- Created cluster visualization graphs.
- Applied Apriori and FP-Growth algorithms.
- Generated association rules.
- Compared both algorithms using Support Confidence Lift and Execution Time.

## Results

K-Means created 4 clusters.

Hierarchical Clustering created 4 clusters.

DBSCAN identified 6 clusters and 60 noise points.

Apriori and FP-Growth both generated 69 frequent itemsets and 4 association rules.
